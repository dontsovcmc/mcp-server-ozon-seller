# Рейтинг

3 действия в домене `rating`.

| Команда | Описание | Параметры |
|---------|----------|-----------|
| `rating-summary` | Сводка рейтинга продавца | — |
| `rating-history` | История рейтинга | `date_from` (string) *, `date_to` (string) *, `ratings` (list[str]) |
| `quality-rating` | Рейтинг качества | `date_from` (string) *, `date_to` (string) *, `warehouse_id` (int, 0) |

\* — обязательный параметр
